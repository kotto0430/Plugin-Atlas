**Entdecke ChatGPT-Apps in deiner Sprache. Finden → Speichern → Nutzen.**

Plugin Atlas ist ein **kostenloser, inoffizieller Wegweiser**, mit dem du ChatGPT-Apps und Plugins in deiner Sprache finden, speichern und verwenden kannst.

## Funktionen

- **134 Apps, 16 Kategorien und 9 Sprachen** (v3.12)
- Suche nach Name oder Zweck und stöbere nach Kategorie
- Speichere Favoriten unter **Meine Apps**
- Sende mit **In ChatGPT verwenden** eine Anfrage an ChatGPT
- Für Smartphones und Computer; auf einem Android-Gerät getestet

## Plugin Atlas öffnen

**[Plugin Atlas öffnen](https://kotto0430.github.io/Plugin-Atlas/)**

Falls ein 404-Fehler erscheint, ist die Veröffentlichung über GitHub Pages möglicherweise noch nicht abgeschlossen.

## So funktioniert es

Website öffnen → Sprache wählen → App suchen → unter Meine Apps speichern → Verwenden auswählen.

## Datenschutz

Favoriten und Spracheinstellungen werden lokal im Browser gespeichert. Beim Löschen der Browserdaten können sie verloren gehen. Sie werden nicht mit den in ChatGPT installierten Apps synchronisiert.

## Wichtiger Hinweis

Plugin Atlas ist **kein offizielles Produkt von OpenAI**. Verfügbarkeit und Voraussetzungen der Apps können variieren. Die Schaltfläche Verwenden sendet eine Anfrage an ChatGPT, garantiert aber weder die Installation noch den Start einer App.

## Aktualisierungen

Die Erfassung öffentlich verfügbarer Informationen ist dienstags um 23:59 Uhr japanischer Zeit geplant. Übersetzung, Kategorisierung und Veröffentlichung neuer Apps erfolgen noch nicht automatisch.
