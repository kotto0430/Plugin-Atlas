# 🌏 Plugin Atlas

[English](../README.md) · [日本語](README.ja.md) · [Esperanto](README.eo.md) · [Français](README.fr.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [中文](README.zh.md) · [한국어](README.ko.md)

**내 언어로 ChatGPT 앱을 찾아보세요. 발견 → 저장 → 사용.**

Plugin Atlas는 ChatGPT 앱과 플러그인을 **원하는 언어로 찾고, 저장하고, 사용할 수 있도록 돕는 무료 비공식 안내 서비스**입니다.

## 주요 기능

- **42개 앱, 12개 카테고리, 9개 언어** 지원(v2.9 계열)
- 이름이나 용도로 검색하고 카테고리별로 탐색
- 즐겨찾는 앱을 **내 앱**에 저장
- **ChatGPT에서 사용** 버튼으로 요청 내용을 ChatGPT에 전달
- 스마트폰과 PC 지원, Android 실제 기기에서 테스트 완료

사이트 열기 → 언어 선택 → 앱 찾기 → 내 앱에 저장 → 사용 버튼 누르기.

## 개인정보 보호

즐겨찾기와 언어 설정은 브라우저에 로컬로 저장됩니다. 브라우저 데이터를 삭제하면 사라질 수 있습니다. ChatGPT에 설치된 앱 목록과 자동으로 동기화되지 않습니다.

## 중요 안내

Plugin Atlas는 **OpenAI의 공식 제품이 아닙니다**. 앱 제공 여부와 사용 조건은 환경에 따라 다릅니다. 사용 버튼은 요청을 ChatGPT에 전달하지만 앱 설치나 실행을 보장하지 않습니다.

## 업데이트

공개 정보 수집은 매주 화요일 일본 시간 23:59에 실행되도록 설정되어 있습니다. 새로운 앱의 번역, 분류, 공개는 아직 자동화되지 않았습니다.
