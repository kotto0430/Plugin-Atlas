# 🌏 Plugin Atlas

[English](../README.md) · [日本語](README.ja.md) · [Esperanto](README.eo.md) · [Français](README.fr.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [中文](README.zh.md) · [한국어](README.ko.md)

**ChatGPTのアプリを、あなたの言語で探そう。見つける → 保存する → 使う。**

Plugin Atlasは、ChatGPTで利用できるアプリやプラグインを**自分の言語で探し、保存し、呼び出す**ための無料・非公式ガイドです。

## 主な機能

- **117アプリ・14カテゴリー・9言語**に対応（v3.11）
- アプリ名や用途で検索し、カテゴリー別に閲覧
- 「マイアプリ」にお気に入りを保存し、すぐに呼び出す
- 「ChatGPTで使う」で依頼文をChatGPTへ渡す
- スマートフォン・PC対応。Android実機で動作確認済み

## アプリを開く

**[アプリを開く](https://kotto0430.github.io/Plugin-Atlas/)**

GitHub Pagesの公開処理中は404が表示される場合があります。

## 使い方

サイトを開く → 言語を選ぶ → アプリを探す → マイアプリに登録 → 「使う」を押す。

## 不具合報告・掲載希望

[🐛 不具合を報告する](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=bug_report.yml) · [💡 改善案・アプリ掲載希望](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=feature_request.yml)

不具合報告には、表示言語、端末・ブラウザ、再現手順を記入してください。**メールアドレス、パスワード、認証情報、個人情報は公開しないでください。**

## プライバシー

お気に入りと言語設定はブラウザ内に保存されます。ブラウザのデータを消去すると失われる場合があります。ChatGPTのインストール済みアプリ一覧とは同期しません。

## 重要な注意

Plugin Atlasは**OpenAIの公式製品ではありません**。アプリの提供状況や利用条件は環境によって異なります。「使う」ボタンは依頼文をChatGPTに渡しますが、アプリのインストールや起動を保証しません。
