**Trouvez les applications ChatGPT dans votre langue. Découvrez → Enregistrez → Utilisez.**

Plugin Atlas est un **guide gratuit et non officiel** pour découvrir, enregistrer et utiliser les applications et extensions ChatGPT dans votre langue.

## Fonctionnalités

- **117 applications, 14 catégories et 9 langues** (v3.11)
- Recherche par nom ou usage, navigation par catégorie
- Enregistrez vos favoris dans **Mes applications**
- Envoyez une demande à ChatGPT avec le bouton **Utiliser**
- Compatible mobile et ordinateur, testé sur un appareil Android

## Ouvrir Plugin Atlas

**[Ouvrir Plugin Atlas](https://kotto0430.github.io/Plugin-Atlas/)**

Une erreur 404 peut apparaître tant que le déploiement GitHub Pages n'est pas terminé.

## Comment l'utiliser

Ouvrez le site → choisissez votre langue → trouvez une application → ajoutez-la à Mes applications → appuyez sur Utiliser.

## Signaler un problème ou proposer une amélioration

[🐛 Signaler un bug](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=bug_report.yml) · [💡 Proposer une fonction ou une application](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=feature_request.yml)

Précisez la langue, l'appareil, le navigateur et les étapes pour reproduire le problème. **Ne publiez pas d'adresse e-mail, de mot de passe, d'identifiant secret ou de données personnelles.**

## Confidentialité

Les favoris et la langue sont enregistrés localement dans votre navigateur. Ils peuvent disparaître si vous effacez les données du navigateur. Ils ne sont pas synchronisés avec les applications installées dans ChatGPT.

## Important

Plugin Atlas **n'est pas un produit officiel d'OpenAI**. La disponibilité et les conditions d'utilisation varient. Le bouton Utiliser transmet une demande à ChatGPT sans garantir l'installation ni le lancement de l'application.

## Mises à jour

La collecte d'informations publiques est programmée chaque mardi à 23 h 59 (heure du Japon). La traduction, la catégorisation et la publication des nouvelles applications ne sont pas encore automatisées.
