**Encuentra aplicaciones de ChatGPT en tu idioma. Descubre → Guarda → Usa.**

Plugin Atlas es una **guía gratuita y no oficial** para descubrir, guardar y utilizar aplicaciones y complementos de ChatGPT en tu idioma.

## Funciones principales

- **117 aplicaciones, 14 categorías y 9 idiomas** (v3.11)
- Búsqueda por nombre o función y exploración por categorías
- Guarda tus favoritas en **Mis apps**
- Envía una solicitud a ChatGPT con el botón **Usar**
- Compatible con móviles y ordenadores; probado en un dispositivo Android

## Abrir Plugin Atlas

**[Abrir Plugin Atlas](https://kotto0430.github.io/Plugin-Atlas/)**

Si aparece un error 404, es posible que GitHub Pages aún esté publicando el sitio.

## Cómo usarlo

Abre la web → elige tu idioma → busca una aplicación → guárdala en Mis apps → pulsa Usar.

## Informar de errores y sugerir mejoras

[🐛 Informar de un error](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=bug_report.yml) · [💡 Sugerir una función o aplicación](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=feature_request.yml)

Indica el idioma, dispositivo, navegador y pasos para reproducir el error. **No publiques direcciones de correo, contraseñas, claves de acceso ni información personal.**

## Privacidad

Los favoritos y el idioma se guardan localmente en tu navegador. Pueden desaparecer si borras sus datos. No se sincronizan con las aplicaciones instaladas en ChatGPT.

## Aviso importante

Plugin Atlas **no es un producto oficial de OpenAI**. La disponibilidad y los requisitos de cada aplicación pueden variar. El botón Usar envía una solicitud a ChatGPT, pero no garantiza la instalación ni la ejecución de la aplicación.

## Actualizaciones

La recopilación de información pública está programada para los martes a las 23:59 (hora de Japón). La traducción, clasificación y publicación de nuevas aplicaciones todavía no son automáticas.
