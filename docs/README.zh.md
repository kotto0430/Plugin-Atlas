# 🌏 Plugin Atlas

[English](../README.md) · [日本語](README.ja.md) · [Esperanto](README.eo.md) · [Français](README.fr.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [中文](README.zh.md) · [한국어](README.ko.md)

**用自己的语言寻找 ChatGPT 应用。发现 → 收藏 → 使用。**

Plugin Atlas 是一款**免费、非官方的多语言指南**，帮助你查找、收藏和使用 ChatGPT 应用及插件。

## 主要功能

- **117 款应用、14 个类别、9 种语言**（v3.11）
- 按名称或用途搜索，按类别浏览
- 将常用应用收藏到**我的应用**
- 点击**在 ChatGPT 中使用**，向 ChatGPT 发送请求
- 支持手机和电脑，已在 Android 真机上测试

## 打开 Plugin Atlas

**[打开 Plugin Atlas](https://kotto0430.github.io/Plugin-Atlas/)**

如果显示 404，可能是 GitHub Pages 尚未完成部署。

## 使用方法

打开网站 → 选择语言 → 查找应用 → 收藏到“我的应用” → 点击“使用”。

## 隐私说明

收藏记录和语言设置保存在浏览器本地。清除浏览器数据可能导致记录丢失。这些信息不会与 ChatGPT 中已安装的应用同步。

## 重要说明

Plugin Atlas **不是 OpenAI 官方产品**。应用的可用性和使用条件可能因用户而异。“使用”按钮会向 ChatGPT 发送请求，但不保证应用已安装或能够启动。

## 更新机制

公开信息采集计划于每周二日本时间 23:59 运行。新应用的翻译、分类和发布目前尚未实现全自动化。
