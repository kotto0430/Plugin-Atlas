# 🌏 Plugin Atlas

**Trovu ChatGPT-aplikaĵojn en via propra lingvo. Malkovru → Konservu → Uzu.**

Plugin Atlas estas **senpaga, neoficiala gvidilo** por trovi, konservi kaj uzi ChatGPT-aplikaĵojn kaj kromprogramojn en via lingvo.

## Ĉefaj funkcioj

- **117 aplikaĵoj, 14 kategorioj kaj 9 lingvoj** (v3.11)
- Serĉu laŭ nomo aŭ celo kaj esploru laŭ kategorio
- Konservu ŝatatajn aplikaĵojn en **Miaj aplikaĵoj**
- Sendu proponitan peton al ChatGPT per la butono **Uzi**
- Funkcias en poŝtelefonoj kaj komputiloj; provita en Android-aparato

## Malfermi Plugin Atlas

**[Malfermi Plugin Atlas](https://kotto0430.github.io/Plugin-Atlas/)**

Se aperas eraro 404, la publikigo per GitHub Pages eble ankoraŭ daŭras.

## Kiel uzi

Malfermu la retejon → elektu lingvon → trovu aplikaĵon → konservu ĝin en Miaj aplikaĵoj → premu Uzi.

## Raporti erarojn kaj proponi ideojn

[🐛 Raporti eraron](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=bug_report.yml) · [💡 Proponi funkcion aŭ aplikaĵon](https://github.com/kotto0430/Plugin-Atlas/issues/new?template=feature_request.yml)

Bonvolu indiki la lingvon, aparaton, retumilon kaj paŝojn por reprodukti la problemon. **Ne publikigu retadresojn, pasvortojn, alirŝlosilojn aŭ privatajn informojn.**

## Privateco

Ŝatataj aplikaĵoj kaj lingvaj preferoj estas konservataj loke en via retumilo. Forviŝi retumilajn datumojn povas forigi ilin. Ili ne sinkroniĝas kun la instalitaj aplikaĵoj de ChatGPT.

## Grava rimarko

Plugin Atlas **ne estas oficiala produkto de OpenAI**. Havebleco kaj postuloj de aplikaĵoj varias. La butono Uzi sendas peton al ChatGPT, sed ne garantias instaladon aŭ lanĉon de aplikaĵo.
